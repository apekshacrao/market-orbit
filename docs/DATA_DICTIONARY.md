# Data Dictionary

## Campaign Dataset Fields

| Field Name | Type | Required | Description | Example |
| :--- | :--- | :--- | :--- | :--- |
| `campaign_name` | String | Yes | Name / identifier of campaign | "Summer Sale 2026" |
| `channel` | String | Yes | Marketing channel / platform | "Google Ads", "Meta Ads" |
| `impressions` | Integer | No | Total ad impressions served | 50000 |
| `clicks` | Integer | No | Total link clicks recorded | 2500 |
| `spend` | Float | Yes | Total ad spend in USD | 1200.00 |
| `conversions` | Integer | No | Total converted actions | 180 |
| `revenue` | Float | Yes | Total attributed revenue in USD | 4500.00 |
| `date` | Date | No | Campaign record date | "2026-06-01" |
